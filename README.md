# 🎧 GLPI Desk - Management & IT Service Support

O **GLPI Desk** é um sistema web de Help Desk desenvolvido para gerenciar chamados de suporte técnico de TI, permitindo a comunicação eficiente entre clientes/solicitantes e as equipes de suporte (N1, N2 e N3).

---

## 🚀 Tecnologias Utilizadas

- **React.js** (Front-end)
- **React Router Dom** (Navegação e Gestão de Rotas)
- **Context API** (Gerenciamento de Estado Global de Autenticação)
- **CSS3 / Flexbox / CSS Grid** (Estilização e Responsividade)
- **LocalStorage** (Persistência temporária para testes offline / Mocking de dados)

---

## 💻 Como Rodar o Projeto Localmente

### Pré-requisitos
Ter o **Node.js** e o **Git** instalados na sua máquina.

### Passo a Passo

1. **Clonar o repositório:**
   ```bash
   git clone [https://github.com/BrunnoRosa/HELPDESK-FRONTEND.git](https://github.com/BrunnoRosa/HELPDESK-FRONTEND.git)
2. **Acessar a pasta do projeto:**
   ```bash
   cd HELPDESK-FRONTEND
3. **Instalar as dependências do projeto:**
   ```bash
   npm install
4. **Executar a aplicação em modo de desenvolvimento:**
   ```bash
   npm run dev
